# Mikhail Panichev

I write code, design solutions, and lead development teams.

I've worked on both building software and organizing the work around it — from requirements and architecture to CI/CD and working with clients. I prefer clear processes and practical solutions grounded in a project's constraints and the team's experience.

I currently work on the business travel interface at [Yandex Go for Business](https://business.go.yandex/travel).

- [Measures](https://github.com/denisinvader/measures) — a tool for measuring elements and spacing on web pages. [Live demo](https://measures.mpanichev.ru/).
- [terraform-provider-regru](https://github.com/denisinvader/terraform-provider-regru) — manage REG.RU DNS records with Terraform.
- [react-strapi-image](https://github.com/denisinvader/react-strapi-image) — React components for responsive images from Strapi.
- [autonbsp](https://github.com/denisinvader/autonbsp) and [remark-plugin-autonbsp](https://github.com/denisinvader/remark-plugin-autonbsp) — non-breaking spaces for text and Markdown.
- [switch-query](https://github.com/denisinvader/switch-query) — a React component for working with TanStack Query states and types.
